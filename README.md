# Beauty Growth Copilot 🌟

AI-помощник для роста бьюти-бизнеса: от частных мастеров до небольших салонов.

## 🎯 О проекте

**Проблема:** Мастера и владельцы салонов красоты тратят слишком много времени на рутину (напоминания, запись, ответы на вопросы) и теряют деньги из-за:
- Клиентов, которые не возвращаются
- No-show (отмены и неявки)
- Низкого среднего чека
- Отсутствия системного подхода

**Решение:** Платформа с AI-аудитом и коробочными микро-SaaS решениями, которые:
- Не требуют обучения (поставил и забыл)
- Работают автоматически
- Окупаются с 1-2 клиентов
- Стоят дешевле одной процедуры

##  Как это работает

1. **Выбор ниши** → Клиент выбирает свою специализацию (маникюр, косметология, салон и т.д.)
2. **Экспресс-аудит** → 10-12 вопросов о бизнесе (3 минуты)
3. **AI-анализ** → Система определяет 3 главные точки роста
4. **Готовое решение** → Предлагаем конкретный продукт под боль клиента

## 📦 Продукты

- **Бот-Реаниматор** — автоматический возврат "уснувших" клиентов
- **AI-Помощник по ценам** — скрипты ответов на возражения и расчет цен
- **Система сбора отзывов** — автоматизация работы с репутацией
- **Генератор допродаж** — персонализированные скрипты upsell
- **Страж клиентской базы** — для салонов (защита от ухода клиентов с мастером)
- **AI-Радар эффективности** — аналитика по мастерам для владельцев

## 🛠️ Технологический стек

- **Frontend:** Tilda (лендинг + квизы)
- **Backend:** Make (Integromat) / n8n
- **AI:** OpenAI GPT-4o-mini
- **Delivery:** Telegram Bot / Email

4. Массаж / SPA

## 👥 Целевая аудитория

- Частные мастера (1-30 клиентов/мес)
- Владельцы небольших студий (2-5 мастеров)
- Владельцы салонов красоты (6-20 мастеров)

## 💰 Бизнес-модель

- **Freemium:** Бесплатный AI-аудит → платные продукты
- **Micro-SaaS:** Подписка 390-2490 ₽/мес
- **One-time:** Коробочные решения 490-1990 ₽
